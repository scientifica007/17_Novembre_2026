# لقاء أساتذة TAG – 17/11/2026

موقع تفتيشي تفاعلي لمؤسسة شيحاني بشير تبسة، المستوى الخامس تقني سامٍ.

## الروابط
- الموقع الرئيسي: index.html?phase=pre
- الاستبيان الختامي: index.html?phase=post
- الرسوم البيانية: index.html?view=results
- لوحة المفتش: admin.html

## النشر
افتح إعدادات المستودع Settings > Pages ثم Deploy from a branch > main > /(root) > Save، وبعد ذلك تحقق من فتح الرابط النهائي على الهاتف.

## البنية
- Frontend: HTML + CSS + JavaScript ملائم للهواتف وRTL.
- Database: Supabase في مشروع موجود مسبقًا.
- Anonymous: لا تُطلب أسماء أو حسابات أو بريد إلكتروني للأساتذة. قد تحتفظ جهة الاستضافة بسجلات تقنية؛ لا يعد ذلك ضمانًا مطلقًا لإخفاء الهوية.
- إجابات الأساتذة: لا تتاح للعموم. الإجراءات المخزنة تعالجها في الخادم.
- الإحصاءات: تجميع مخفي إلى أن تتوافر 3 استجابات على الأقل لكل مرحلة، مع تحديث الشاشة كل 15 ثانية.
- لوحة المفتش: دخول بواسطة حساب Supabase المصرح له، تصدير JSON أو CSV.
- منع تكرار التسجيل في المتصفح الواحد باستخدام sessionStorage إجراء مساعد فقط، وليس ضمانًا لمنع التكرار أو التلاعب.

## أمن البيانات
وظائف قاعدة البيانات: tag_20261117_submit، tag_20261117_stats، tag_20261117_private_results.
قاعدة البيانات تستخدم صلاحيات SQL محدودة؛ مفتاح sb_publishable عمومي بحسب تصميم Supabase ولا يمنح صلاحيات الإدارة.
يجب الامتناع عن عرض النصوص الحرة للحاضرين إذا تضمنت تفاصيل تحدد هويات أصحابها.
